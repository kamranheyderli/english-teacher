# english-teacher

Portfolio website for Rəşidə Həqiqətli, English teacher. Built with Next.js 15, React Three Fiber (Three.js), and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Editing content

- Site text, contacts, experience, reviews: `data/site.ts`
- Level test questions and results: `data/quiz.ts`
- Photo: `public/teacher.jpg`
